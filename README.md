# Cool-Mod-Website-Concept

Static concept site for **JTAG Fury — Custom Xbox Builds**: a custom-modded
Xbox storefront/landing concept ("Unlock the Impossible").

Plain HTML/CSS/JS, no build step. CI (`.github/workflows/ci.yml`) validates
the HTML with `tidy` and checks internal links/anchors with `lychee`.

Open `index.html` in a browser to view.
